# Time-lag bias in posting results and adverse events for RCTs: a cross-sectional analysis

## Project Overview
This project examines the timeliness of results and adverse event posting on ClinicalTrials.gov for randomized clinical trials (RCTs) published in ICMJE member journals.

## Files

| File | Description |
|------|-------------|
| Posting_results_AEs_codebook_v2.csv | Variable definitions for trial-level data used in this study |
| Posting_CTG_trial_level_data_v2.csv | Dataset of trial-level data from the original ClinicalTrials.gov API pull |
| Posting_Update_CTG_trial_level_data_v2.csv | Dataset of trial-level data from the final ClinicalTrials.gov API pull |
