# Time-lag bias in posting results and adverse events for RCTs: a cross-sectional analysis

## Project Overview
This project examines the timeliness of results and adverse event posting on ClinicalTrials.gov for randomized clinical trials (RCTs) published in ICMJE member journals.

## Files

| File | Description |
|------|-------------|
| Posting_results_AEs_codebook.csv | Variable definitions for trial-level data used in this study |
| CTG_posting_results_AEs_analysis.R | Code used for analysis of results and adverse event posting timeliness |
| Plotting_results_posting.R | Code used to generate figures for cumulative results posting after journal publication |
