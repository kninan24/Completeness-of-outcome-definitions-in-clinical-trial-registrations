# Outcome definitions in clinical trial registrations: a cross-sectional study

## Project Overview
This project examines the completeness of outcome reporting in randomized clinical trials (RCTs) published in clinicaltrials.gov.

## Files

| File | Description |
|------|-------------|
| codebook.csv | Variable definitions for trial and outcome-level data from ClinicalTrials.gov, and for agreement between human raters |
| Trial_Level_Code_Outcome_Completeness.sas | Code used for analysis of trial-level data from ClinicalTrials.gov |
| Outcome_Level_Code_Outcome_Completeness.sas | Code used for analysis of outcome-level data from ClinicalTrials.gov |
| human_agree.sas | Code used for analysis of agreement between human raters |
| LLM_Performance_Metrics.R | Code used for analysis of agreement between LLM and human ratings |
| Bootstrapping_95%_CIs.R | Code used for bootstrapping 95% CIs |
| Plotting_Completeness.R | Code used to generate figures for outcome completeness by subgroups |
